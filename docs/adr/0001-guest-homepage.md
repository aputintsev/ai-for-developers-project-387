# Публичная главная страница Гостя

По адресу `/` открывается публичная страница Гостя с заголовком «Календарь звонков». Главная даёт Гостю выбор между началом записи и просмотром своих предстоящих записей. Вход в раздел Владельца остаётся доступен с той же страницы.

- Основная кнопка «Записаться» ведёт на отдельную страницу выбора типа встречи.
- Второстепенная кнопка «Предстоящие записи» ведёт на отдельную страницу записей Гостя.
- Под кнопками расположена текстовая ссылка «Раздел Владельца».
