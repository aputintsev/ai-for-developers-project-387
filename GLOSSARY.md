# Календарь звонков

Сервис записи на звонки с одним Владельцем календаря.

## Термины

**Владелец**:
Человек, на звонок с которым может записаться Гость. Владелец задаёт типы встреч.

**Гость**:
Человек, который записывается на звонок с Владельцем.

**Тип встречи**:
Вариант звонка с Владельцем с заданными названием, описанием и длительностью.

**Запись**:
Подтверждённое бронирование Гостем времени для звонка с Владельцем по выбранному типу встречи.
_Avoid_: Событие

**Тема разговора**:
Короткое описание того, что Гость хочет обсудить; заполняется при записи, до 100 символов.

**Окно записи**:
Период из 21 календарного дня, на которые Гость может записаться. Начинается с завтрашнего дня по времени Владельца.

**Свободный слот**:
Интервал для звонка по выбранному типу встречи, который доступен для записи Гостя. Его длительность совпадает с длительностью типа встречи.
